
# **使用CatTuber进行直播或录制的方法&常见问题**

### **工具的选择**

**任何情况下都推荐使用OBS进行直播或录制。**

需要在不使用OBS的情况下与游戏一起录制CatTuber的画面的话，需要你的工具有以下能力：

画面编排:
在非直接录制屏幕的情况下，需要能编辑画面内容以在游戏画面之上添加来自其他窗口的内容。

画面捕获:
以游戏的方式捕获其他窗口（最优推荐）
以窗口的方式捕获其他窗口
虚拟摄像头（涉及涉及大量GPU到CPU和CPU到CPU的内存拷贝，性能最差）

### **背景去除**

如果是以游戏捕获获取CatTuber画面，在游戏捕获的设置页面勾选 **"允许窗口透明"**.

对于其他无法获取透明通道的捕获，可先设置CatTuber窗口背景颜色为合适颜色，然后以去除特定颜色的方式去除背景.

### **性能**

使用非透明窗口的CatTuber配合游戏捕获时能获得最佳性能。

窗口捕获次之，因为多了一次CPU到CPU的复制、多了一次背景透明处理。

虚拟摄像头最次，这是涉及内存复制最多的方案（CatTuber内部需要每帧将GPU中的画面输出到CPU内存然后送入虚拟摄像头，OBS也要先获取虚拟摄像头中的画面到OBS自己的内存中，而不是像游戏捕获那样直接获取显卡内部画面地址）。

对于CatTuber自身，CatTuber可以在最小化或隐藏时也能被OBS捕获。
使用透明窗口且不最小化或隐藏CatTuber窗口时，会在操作系统处理窗口透明效果时消耗掉小部分性能。

### **无法捕获画面时的应对**

#### **由权限导致的无法捕获**

CatTuber、OBS（或你的直播录制工具）、游戏需要至少相同的权限，因为CatTuber权限低于游戏时，CatTuber将无法正常获取游戏窗口中的设备输入，OBS权限低于游戏或CatTuber时，OBS将无法获取画面。

CatTuber可在软件设置页中勾选是否需要管理员权限。

OBS如果下载自其官网，那么它通常会在启动时自动获取管理员权限；而如果下载自Steam，OBS将不会自动获取管理员权限。解决方案是寻找到OBS本地程序文件，通过对其右键→属性→兼容性→以管理员身份运行此程序来设置下载自Steam的OBS的管理员权限，然后通过直接运行程序或其快捷方式的形式运行OBS，而不是通过Steam或Steam创建的快捷方式运行OBS。

#### **由显卡设置导致的无法捕获**

OBS需要与CatTuber或游戏使用同一张显卡才能获取画面，因此对于有多张显卡的电脑（通常是一张独立显卡+一个来自CPU自带的显卡），请将OBS、CatTuber、游戏都设置为使用电脑上的高性能显卡。

### **画面异常**

#### **预期之外的轮廓**

通常是CatTuber与直播软件对画面边缘半透明像素的处理问题。

如果采用非游戏捕获+关键色去背景的方式，请在你所使用的工具的关键色去除背景相关的地方寻找"颜色容差"的设置项。

如果采用透明的游戏捕获，可以尝试调整OBS中游戏捕获设置项中的"预乘"、尝试将CatTuber背景色调整为纯黑或纯白、尝试调整CatTuber设置项中的"预乘"，直到CatTuber在OBS中无显眼轮廓。
